# Проверка опоры утверждений

Проверка утверждений в агенте намеренно консервативна. Совпадение числа или общих слов само по себе не делает
утверждение подтверждённым. Для `verified` нужна опора в конкретной цитате: сверяются число и единица измерения,
названный показатель, направление изменения, отрицание, факт или прогноз, год и явно названная база периода.
Например, ставка 14 % не доказывает инфляцию 14 %, 2 % не равно 2 процентным пунктам, а значение на конец
2026 года не подтверждает прогноз на конец 2027 года. Периоды «в день», «в неделю», «в месяц» и «в год»
сверяются отдельно: 14 % годовых не подтверждаются ставкой 14 % в месяц. Для денежных величин сверяется и
масштаб, и валюта: 14 млрд ₽ не подтверждают 14 млрд $.

Если цитата относится к теме, но даёт лишь частичную опору или не позволяет связать показатель с утверждением,
статус остаётся `partly`. Противоречие направления, периода или прогноза фиксируется как проблема проверки.
Утверждения с неподтверждёнными числами без другой опоры могут быть удалены из пользовательской карточки.
Точные результаты расчётного инструмента сохраняют отдельный путь верификации и не приравниваются к цитатам:
совпадающий результат из контекста расчётов остаётся допустимым `estimate`.

## Синтетическая регрессия

Файл `scripts/data_reasoning_cases.json` содержит 23 вручную заданные синтетические пары утверждение/цитата,
включая подмену показателя, единицы, периода начисления, валюты, масштаба и направления, а также несколько корректных вариантов.
Это воспроизводимая регрессионная выборка для обнаружения известных классов ошибок. Она не является независимым
holdout-набором, не представляет реальные документы и не измеряет точность на рабочем потоке.

Запуск из корня репозитория:

```powershell
python -m uv run --project apps/api python scripts/evaluate_data_reasoning.py
```

Скрипт печатает фактическое число проверок, прошедшие и ошибочные случаи с идентификаторами. Чтобы выполнить
юнит-тесты агента, используйте окружение API:

```powershell
python -m uv run --project apps/api pytest apps/api/tests/test_data_reasoning.py apps/api/tests/test_agent_claims.py apps/api/tests/test_agent_checks.py
```

Результат этого небольшого набора следует трактовать только как прохождение или регрессию перечисленных примеров,
а не как процент достоверности продукта.
