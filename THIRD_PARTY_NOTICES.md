# Сторонние компоненты

Перечень сторонних компонентов, моделей, датасетов, сервисов и смоделированных интеграций. Пополняется вместе с кодом.

## Языковые модели

Используются только модели из списка, разрешённого организаторами кейса, через предоставленный организаторами доступ.

| Модель | Для чего |
|---|---|
| Qwen3-VL-30B-A3B-Instruct | распознавание таблиц и слайдов в PDF аналитики банка: один раз, с кэшем по страницам |
| Gemma 4 26B A4B | разметка новостей факторами поверх словарей (по флагу, по умолчанию выключена) |
| Gemma 4 26B A4B | агент: план (какие факторы и каналы проверить, что искать) |
| DeepSeek-V4.1-Flash | агент: черновик инсайта, доработка после самопроверки, ответ на уточняющий вопрос |

Храним заголовок, лид дословно (до 500 знаков), ссылку, издателя, дату, ссылку на картинку материала и на значок
издания. Файлы картинок не скачиваем и не храним: интерфейс показывает их по ссылке с сайта издателя. Полный текст
храним только там, где условия это разрешают: Банк России, Правительство, ФНС (со страницы материала) и Forbes
(издатель сам публикует полный текст в ленте; показываем с автором, датой и ссылкой). У остальных — только лид,
в интерфейсе ведём на первоисточник; пейволлы не обходим. Запись берётся, только если ссылка ведёт на домен самой ленты, поэтому издатель в
карточке всегда верный. Надёжность источника задана у ленты и учитывается в «качестве источника» при ранжировании.
Условия проверены 24.10.2026.

Каталог источников для бизнеса с условиями подключения (в том числе платных API: Reuters/LSEG, Dow Jones Factiva,
Financial Times, NewsAPI.org, Marketaux, Cbonds, СПАРК-Интерфакс) — `apps/ingest/src/ingest/news/catalog.toml`.
Платные API в прототипе не подключены; в каталоге — только то, что подтверждено документацией, остальное помечено.

Есть в `apps/ingest/src/ingest/news/sources.toml`, но выключены:

| Источник | Причина |
|---|---|
| ТАСС | условия не найдены, из сети разработки лента не открывается |
| РБК | автоматическое извлечение без письменного разрешения запрещено |
| Ведомости | автоматически извлечённое — только с разрешения |
| Финмаркет | автоматическое извлечение и кэширование без разрешения запрещены |
| ПРАЙМ | материалы только для личного некоммерческого использования |
| Минфин России | лента отвечает 403 автоматическим клиентам |
| Минэкономразвития, Минпромторг, ФАС, Минсельхоз | из сети разработки сайты не отвечают, условия не проверены |
| Росстат | сертификат российского УЦ, стандартная проверка TLS его не принимает |
| Минэнерго России, Frank Media | ленты открываются, условий использования на сайтах не нашли |
| Московская биржа | соглашение (PDF) не открылось; в ленте в основном технические сообщения |

Открытых отраслевых лент (авто, топливо, агро, общепит) не нашли: Автостат, Агроинвестор и Neftegaz.ru не отвечают,
у oilcapital.ru лента пустая, Restoclub отвечает 503.
