# Веб-интерфейс

Макет главной интернет-банка для бизнеса и сервис «Новости» внутри него. Вход — по тестовой учётке. Главная
сервиса: «Главное за день» (важно ли событие для компании, почему — с числом из данных, что делать), позиция
Альфа-Банка с подписью аналитиков и одна главная кнопка «Обсудить с менеджером», лента событий с картинками и
фильтрами по теме. Карточка — новость целиком с подсвеченными цитатами, на которые опирается вывод, «Обсудить
новость» и панель вывода справа. Пока разбор собирается, видны его живые шаги. «Источники» — что подключено и как
подключить платный источник по API; там же разбор своей новости. На экранах сервиса — оговорка, что материалы не
являются инвестиционной рекомендацией. Анимации учитывают `prefers-reduced-motion`; иконки — Lucide.

| Адрес | Экран |
|---|---|
| `/login` | вход по тестовой учётке |
| `/` | главная интернет-банка с плашкой сервиса |
| `/radar` | «Новости»: главное за день и лента событий |
| `/radar/<событие>` | новость целиком и вывод для компании; пока разбор собирается — его шаги |
| `/radar/search?q=` | поиск по новостям |
| `/radar/sources` | источники и разбор своей новости |
| `/radar/analyze` | разбор своей новости по ссылке или тексту |
| `/radar/map` | к чему уязвима компания |
| `/radar/trace/<трасса>` | как получен вывод: шаги агента |

Новые поля API (`takeaway`, `image_url`, `source_icon_url`, `verdict`, `bank_position`, `quotes`, живые `steps`,
`GET /api/events/{id}`, `/api/search`, `/api/sources/catalog`) необязательны: если их нет, экран показывает запасной
вид — короткую строку из данных вместо вывода, иллюстрацию по теме вместо картинки, фрагмент новости вместо
полного текста, поиск по ленте, издания из ленты вместо каталога.

Стек: React 19, TypeScript, Vite, React Router. Сборка в Docker — статический бандл под nginx.

## Запуск для разработки

```bash
npm ci
npm run dev        # http://localhost:5173
```

| Скрипт | Что делает |
|---|---|
| `npm run dev` | дев-сервер с горячей перезагрузкой |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run typecheck` | только проверка типов |
| `npm run lint` | ESLint |
| `npm test` | тесты селекторов экранов |

## Данные — только из API

Интерфейс берёт данные только из настоящего API: лента `GET /api/briefing?persona=`, карта
`GET /api/companies/{id}/exposure`, разбор `GET /api/insights/{event_id}?persona=&wait=false` (202 — собирается в фоне,
статус с этапами — `GET /api/insights/{event_id}/status?persona=` раз в 1,5 с), вопрос `POST /api/insights/{id}/ask`,
трасса `GET /api/traces/{id}`, своя новость `POST /api/analyze`, отзыв `POST /api/feedback`. Тестовые данные из
`src/mocks` остались только для тестов.

| Переменная | Значение |
|---|---|
| `VITE_API_URL` | адрес API; пусто — тот же адрес: в разработке через прокси dev-сервера, в образе — через nginx |
| `API_PROXY_TARGET` | куда dev-сервер проксирует `/api`, по умолчанию `http://127.0.0.1:8000` |
| `API_UPSTREAM` | (образ) куда nginx проксирует `/api`, по умолчанию `http://api:8000` — сервис `api` из compose. Только схема, хост и порт, без пути. Имя разрешается DNS Docker (`127.0.0.11`), поэтому образ рассчитан на запуск в сети compose |

Своя проверка, не трогая общий стек на 8000: `API_PORT=8010 DB_PORT=5443 docker compose -p web up -d db import api`
в корне, затем `API_PROXY_TARGET=http://127.0.0.1:8010 npm run dev`; после — `docker compose -p web down -v`.

## Интерфейс = f(состояние)

Экраны не рисуются «под случай»: чистые функции в `src/state/screens.ts` превращают данные API и действия
пользователя (скрытое, фильтр, прошлый визит, роль) в модель экрана, компоненты только её отображают
(`team/docs/06_ui_state.md`). Одинаковое состояние — одинаковый экран; новые факторы, роли и источники не требуют
новых экранов. Селекторы покрыты тестами: `npm test` (node --test, без сборки).

- **Лента** (`feedScreen`): события группируются по фактору влияния, у группы — капс-метка «Ставка · 3 материала ·
  23.10», заголовки новостей с монограммой источника и одна строка «для вас» на группу. Верх зависит от роли:
  финансистам — три показателя из карты чувствительности (значение — из данных банка), собственнику и
  гендиректору — короткий брифинг из трёх пунктов. События значимостью ниже 0,3 свёрнуты.
- **Карточка** (`cardScreen`): первый экран без прокрутки — заголовок, источники, лид, «Что это значит для вас» с
  цифрами из данных и дословной цитатой банка (страница и дата). Целевое действие «Обсудить с менеджером …»
  появляется через 15 с или при прокрутке до конца; нецелевые действия — в меню «Ещё». Подробности — раскрываемые
  блоки справа.

## Тестовые учётки

Вход демонстрационный, это не защита: учётки открыты и проверяются в браузере. Пароль у всех — `radar2026`.

| Логин | Кто это | Компании и роли |
|---|---|---|
| `expert` | эксперт, жюри | все тестовые компании и роли |
| `owner` | собственник | топливный оптовик в холдинге — собственник; зернотрейдер — гендиректор |
| `finance` | финансист | оптовик автозапчастей — финдиректор; зернотрейдер — казначей |
| `horeca` | руководитель | поставщик общепита — гендиректор |

Учётка — человек; у него может быть несколько компаний и ролей. Переключатель вверху экрана показывает только их.
Учётки и их пользователи — в `src/state/accounts.ts`.

## Тестовые пользователи

Четыре обезличенные компании из данных кейса и семь ролей: оптовик автозапчастей (финдиректор, главбух), топливный
оптовик в холдинге (собственник, казначей), зернотрейдер (гендиректор, казначей), поставщик общепита (гендиректор).
Переключатель компании и роли — вверху каждого экрана; смена перестраивает брифинг и плашку на главной. Скрытые
разборы хранятся в браузере отдельно для каждого пользователя; вернуть их можно в брифинге.
Подробные разборы в тестовых данных есть для пяти пар «событие × пользователь», остальные показывают факты, позицию
банка и связь с компанией.

## Где что

| Путь | Что |
|---|---|
| `src/api/types.ts` | типы по контракту API |
| `src/api/client.ts` | клиент API и переключение на тестовые данные |
| `src/mocks/` | тестовые компании, события и разборы |
| `src/pages/` | экраны: вход, главная, брифинг, карточка события, карта чувствительности, сводка недели, трасса, своя новость |
| `src/components/` | оболочка банка, переключатель пользователя, утверждения с источниками, блоки карточки, отзыв |
| `src/bank/` | счета и платежи на главной — только антураж макета |
| `src/styles.css` | тема на значениях токенов открытой дизайн-системы: цвета, шрифт, сетка |

Шрифт — системный (`--font-family` в `src/styles.css`), без загрузки файлов шрифтов. Иконки — `@alfalab/icons-glyph`, по одной (`src/components/Icon.tsx`).
