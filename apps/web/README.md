# Веб-интерфейс

Макет главной интернет-банка для бизнеса и сервис «Радар связей» внутри него: вход под тестовым пользователем,
плашка сервиса на главной, брифинг «что изменилось для вас» с фильтрами по фактору и каналу, карточка события с
разделением «факт / данные банка / позиция банка / вывод модели», цепочкой «через кого вас задевает», позицией банка
против рынка и оценкой в рублях по формуле.

Стек: React 19, TypeScript, Vite, React Router. Сборка в Docker — статический бандл под nginx.

## Запуск для разработки

```bash
npm ci
npm run dev        # http://localhost:5173
```

| Скрипт | Что делает |
|---|---|
| `npm run dev` | дев-сервер с горячей перезагрузкой |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run typecheck` | только проверка типов |
| `npm run lint` | ESLint |

## Данные: тестовые или API

| Переменная | Значение |
|---|---|
| `VITE_API_URL` | адрес API, например `http://localhost:8000`. Пусто — интерфейс работает на встроенных тестовых данных (`src/mocks`) |

Переменная читается при сборке. Для образа: `docker build --build-arg VITE_API_URL=… -t web .`

На тестовых данных можно проверить состояния экранов параметром адреса: `?mock=empty` — пустой брифинг,
`?mock=error` — ошибка всех запросов, `?mock=error-briefing` и `?mock=error-insight` — ошибка только брифинга или
разбора. Режим сохраняется до закрытия вкладки, `?mock=off` его сбрасывает.

Ожидаемые адреса API (предложение, согласуется с бэкендом): `GET /api/personas`, `GET /api/companies/{id}`,
`GET /api/briefing?persona=` (брифинг или список событий), `GET /api/insights/{event_id}?persona=` (204 — событие
не касается компании), `POST /api/feedback`.

## Тестовые пользователи

Четыре обезличенные компании из данных кейса и семь ролей: оптовик автозапчастей (финдиректор, главбух), топливный
оптовик в холдинге (собственник, казначей), зернотрейдер (гендиректор, казначей), поставщик общепита (гендиректор).
Переключатель пользователя — вверху каждого экрана; смена пользователя перестраивает брифинг и плашку на главной.
Подробные разборы в тестовых данных есть для пяти пар «событие × пользователь», остальные показывают факты, позицию
банка и связь с компанией.

## Где что

| Путь | Что |
|---|---|
| `src/api/types.ts` | типы по контракту API |
| `src/api/client.ts` | клиент API и переключение на тестовые данные |
| `src/mocks/` | тестовые компании, события и разборы |
| `src/pages/` | экраны: вход, главная, брифинг, карточка события |
| `src/components/` | оболочка банка, переключатель пользователя, утверждения с источниками, блоки карточки, отзыв |
| `src/bank/` | счета и платежи на главной — только антураж макета |
| `src/styles.css` | тема на значениях токенов открытой дизайн-системы: цвета, шрифт, сетка |

Шрифт переключается одной строкой в `src/styles.css`: `--font-family: var(--font-golos)` или `var(--font-system)`.
Иконки — `@alfalab/icons-glyph`, по одной (`src/components/Icon.tsx`).
