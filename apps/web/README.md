# Веб-интерфейс

Макет главной интернет-банка для бизнеса и сервис «Радар связей» внутри него: вход под тестовым пользователем,
плашка сервиса на главной, брифинг «что изменилось для вас» с фильтрами по фактору и каналу, карточка события с
разделением «факт / данные банка / позиция банка / вывод модели», цепочкой «через кого вас задевает», позицией банка
против рынка и оценкой в рублях по формуле, карта чувствительности компании и сводка недели для печати.

| Адрес | Экран |
|---|---|
| `/login` | выбор тестового пользователя |
| `/` | главная интернет-банка с плашкой сервиса |
| `/radar` | брифинг; `?factor=<код>` — сразу с фильтром по фактору |
| `/radar/map` | к чему уязвима компания |
| `/radar/weekly` | сводка недели (печать на 1–2 страницы A4) |
| `/radar/analyze` | разбор своей новости по ссылке или тексту |
| `/radar/<событие>` | карточка события с уточняющими вопросами |
| `/radar/trace/<трасса>` | как получен вывод: шаги агента |

Стек: React 19, TypeScript, Vite, React Router. Сборка в Docker — статический бандл под nginx.

## Запуск для разработки

```bash
npm ci
npm run dev        # http://localhost:5173
```

| Скрипт | Что делает |
|---|---|
| `npm run dev` | дев-сервер с горячей перезагрузкой |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run typecheck` | только проверка типов |
| `npm run lint` | ESLint |

## Данные: тестовые или API

| Переменная | Значение |
|---|---|
| `VITE_API_URL` | адрес API. Пусто — интерфейс работает на встроенных тестовых данных (`src/mocks`). `/` — API с того же адреса: в разработке через прокси dev-сервера, в образе — через nginx |
| `VITE_API_LIVE` | какие методы уже брать из API, через запятую; по умолчанию `personas,company,health` — то, что в API уже есть. `all` — всё из API. Остальное — тестовые данные |
| `API_PROXY_TARGET` | куда dev-сервер проксирует `/api`, по умолчанию `http://127.0.0.1:8000` |
| `API_UPSTREAM` | (образ) куда nginx проксирует `/api`, по умолчанию `http://api:8000` — сервис `api` из compose. Только схема, хост и порт, без пути. Имя разрешается DNS Docker (`127.0.0.11`), поэтому образ рассчитан на запуск в сети compose |

`VITE_*` читаются при сборке. Локально с API: поднять API (`docker compose up` в корне), затем
`VITE_API_URL=/ npm run dev`. Образ с API: `docker build --build-arg VITE_API_URL=/ -t web .`

В меню слева видно, откуда данные: «тестовые, без API» или «API работает. Из API: пользователи, профили компаний;
остальное — тестовые данные». Для пользователей из API, у которых нет тестовых данных, брифинг, карта и сводка
честно пустые.

На тестовых данных можно проверить состояния экранов параметром адреса: `?mock=empty` — пустой брифинг,
`?mock=error` — ошибка всех запросов, `?mock=error-briefing`, `error-insight`, `error-map`, `error-weekly`,
`error-ask`, `error-trace`, `error-analyze` — ошибка только одного метода. Режим сохраняется до закрытия вкладки, `?mock=off` его сбрасывает.

Ожидаемые адреса API (предложение, согласуется с бэкендом): `GET /api/personas`, `GET /api/companies/{id}`,
`GET /api/briefing?persona=` (брифинг или список событий), `GET /api/insights/{event_id}?persona=` (204 — событие
не касается компании), `GET /api/companies/{id}/exposure-map`, `GET /api/weekly?persona=`, `POST /api/feedback`,
`POST /api/insights/{id}/ask` (`{persona, question}` → `{answer: Statement[], sources}`), `GET /api/traces/{id}`,
`POST /api/analyze` (`{persona_id, url?, text?}` → инсайт или 204).

## Тестовые пользователи

Четыре обезличенные компании из данных кейса и семь ролей: оптовик автозапчастей (финдиректор, главбух), топливный
оптовик в холдинге (собственник, казначей), зернотрейдер (гендиректор, казначей), поставщик общепита (гендиректор).
Переключатель пользователя — вверху каждого экрана; смена пользователя перестраивает брифинг и плашку на главной.
Подробные разборы в тестовых данных есть для пяти пар «событие × пользователь», остальные показывают факты, позицию
банка и связь с компанией.

## Где что

| Путь | Что |
|---|---|
| `src/api/types.ts` | типы по контракту API |
| `src/api/client.ts` | клиент API и переключение на тестовые данные |
| `src/mocks/` | тестовые компании, события и разборы |
| `src/pages/` | экраны: вход, главная, брифинг, карточка события, карта чувствительности, сводка недели, трасса, своя новость |
| `src/components/` | оболочка банка, переключатель пользователя, утверждения с источниками, блоки карточки, отзыв |
| `src/bank/` | счета и платежи на главной — только антураж макета |
| `src/styles.css` | тема на значениях токенов открытой дизайн-системы: цвета, шрифт, сетка |

Шрифт — системный (`--font-family` в `src/styles.css`), без загрузки файлов шрифтов. Иконки — `@alfalab/icons-glyph`, по одной (`src/components/Icon.tsx`).
