# Сбор материалов: новости и аналитика банка

Пакет готовит материалы, на которые опирается сервис: свежие новости из открытых лент и аналитику Центра
макроэкономического анализа Альфа-Банка. Всё приводится к схеме `Source` — общему формату обмена с API.

```
RSS-ленты ──▶ нормализация ──▶ склейка дублей ──▶ разметка ──▶ raw/derived/news.jsonl
                                                     ▲          demo/news_snapshot.jsonl (снимок, в git)
PDF-сканы ──▶ страница в картинку ──▶ распознавание ─┴─▶ фрагменты ──▶ raw/derived/alfa_fragments.jsonl
              (pypdfium2)            (Tesseract,         (абзацы с номером страницы)
                                      кэш по страницам)
```

## Запуск

Одна команда из корня репозитория — соберёт новости и распознает аналитику:

```bash
docker compose -f apps/ingest/compose.yaml run --rm ingest
```

PDF аналитики кладутся в `data/raw/alfa_analytics/` (материалы кейса, в git их нет). Первый прогон распознаёт
64 страницы за 3–6 минут, дальше страницы берутся из кэша `data/raw/derived/ocr/`.

Без Docker (нужны Python 3.12 и [uv](https://docs.astral.sh/uv/)):

```bash
cd apps/ingest
uv sync
uv run ingest all --data ../../data          # новости и аналитика
uv run ingest news --data ../../data --snapshot   # только новости, обновить снимок в data/demo
uv run ingest analytics --data ../../data --force # распознать заново, не глядя в кэш
uv run pytest
```

Локально нужен Tesseract с русским языком: `apt install tesseract-ocr tesseract-ocr-rus`, `brew install tesseract
tesseract-lang`, на Windows — сборка UB Mannheim. Если его нет, фрагменты собираются из кэша распознавания,
а нераспознанные материалы помечаются в отчёте.

| Параметр | Что делает |
|---|---|
| `--data` | каталог данных, по умолчанию `./data` |
| `--engine` | распознавание: `tesseract` (по умолчанию) или `qwen3-vl-mock` |
| `--llm` | разметка моделью поверх словарей: `off` (по умолчанию) или `mock` |
| `--feeds` | свой файл лент вместо встроенного `sources.toml` |
| `--snapshot` | перезаписать `data/demo/news_snapshot.jsonl` |
| `--force` | распознать страницы заново |

## Что получается

| Файл | Содержимое |
|---|---|
| `data/raw/derived/news.jsonl` | новости по схеме `Source`, свежие с последнего запуска |
| `data/raw/derived/alfa_fragments.jsonl` | фрагменты аналитики: абзац, файл, страница, название, дата, уверенность распознавания |
| `data/raw/derived/ocr/<движок>/<материал>/pNNN.{json,txt}` | распознанные страницы: абзацы с рамками и текст для проверки глазами |
| `data/raw/derived/report.json` | отчёт: какие ленты ответили, сколько фрагментов, что и почему отброшено на каждой странице |
| `data/demo/news_snapshot.jsonl` | снимок новостей для работы без сети: заголовок, лид до 500 знаков, ссылка, издатель, дата, разметка |

Если ни одна лента не ответила, `news.jsonl` заполняется из снимка — сервис не остаётся без новостей.

Пример новости:

```json
{"id": "src:news:3f1c…", "kind": "news", "title": "Банк России сохранил ключевую ставку…", "publisher": "Банк России",
 "url": "https://www.cbr.ru/press/pr?file=…", "published_at": "2026-10-23T13:30:00+03:00",
 "fragment": "лид дословно, до 500 знаков",
 "tags": {"topics": ["ключевая ставка"], "sectors": ["финансы и банки"], "okved": ["64", "65", "66"],
          "event_type": "решение регулятора", "regions": [], "countries": ["Россия"], "tagged_by": ["rules"]},
 "also_reported_by": [{"publisher": "Интерфакс", "title": "…", "url": "…", "published_at": "…"}]}
```

Фрагмент аналитики: `id` вида `src:alfa:keyrate-2026-09#p1-3` (материал, страница, номер фрагмента), `kind:
"alfa_analytics"`, `publisher: "Альфа-Банк"`, плюс `file`, `page`, `ocr_confidence`.

Поля сверх контракта (`page`, `file`, `ocr_confidence`, `also_reported_by`, `tags.countries`, `tags.tagged_by`)
необязательные: потребитель, который о них не знает, их пропустит.

## Источники новостей

Список — в [`src/ingest/news/sources.toml`](src/ingest/news/sources.toml): добавить источник — дописать блок, код не
меняется. Включены ленты, условия которых допускают заголовок, лид и ссылку: Банк России, Интерфакс, Коммерсантъ,
РИА Новости, Forbes. ТАСС, РБК, Ведомости и Финмаркет описаны, но выключены — их условия запрещают автоматическое
извлечение без разрешения или не найдены. Подробно — в [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

**Склейка дублей.** Сначала одна и та же ссылка из разных лент, затем один сюжет у разных издателей: совпадение основ
слов в заголовках (Жаккар ≥ 0,5 или короткий заголовок почти целиком внутри длинного) в окне 48 часов. Разные
названия мест и компаний («аэропорт Сочи» и «аэропорт Казани») и разные числа («до 16%» и «до 14%») — разные
события. Главной остаётся запись первоисточника (регулятор раньше СМИ), остальные — в `also_reported_by`.

## Разметка

Базовый слой без языковой модели — словари и правила в
[`src/ingest/tagging/dictionaries.toml`](src/ingest/tagging/dictionaries.toml):

- **темы** — ключевая ставка, инфляция, валюта, нефть и газ, металлы, сырьё, стройка и недвижимость, ритейл и
  потребление, логистика, налоги и регулирование, санкции и ВЭД, госрасходы и бюджет, кредитование, долговой рынок,
  фондовый рынок, рынок труда, экономический рост, энергетика, сельское хозяйство;
- **отрасли** с двузначными кодами ОКВЭД 2 — по ним новость сопоставляется с `MAINOKVED_CODE` компании;
- **тип события** — санкции, решение регулятора, законодательство, статистика, корпоративное событие, рынки, прогноз;
- **регионы** России и **страны**.

Шаблоны ищутся с начала слова, поэтому основа покрывает все формы: `инфляц` найдёт «инфляция» и «инфляционных».
Известные ложные срабатывания закрыты исключениями и тестами: «газета» и «Газпромбанк» — не газ, «розничные инвесторы» —
не ритейл, «Московская биржа» — не регион.

Место для разметки моделью — интерфейс `LlmTagger` в [`src/ingest/tagging/llm.py`](src/ingest/tagging/llm.py): модель
дополняет словари, а не заменяет их. Пока ключа нет, работает заглушка (`--llm mock`).

## Распознавание аналитики

PDF аналитики — сканы без текстового слоя. Страница рендерится в картинку (длинная сторона 3500 px, около 300 dpi) и
распознаётся Tesseract 5 (`rus+eng`) за интерфейсом `OcrEngine` — на Qwen3-VL-30B-A3B-Instruct он переключается
заменой движка (`VisionLlmEngine`, клиент модели подключится вместе с ключом). Страницы распознаются параллельно,
результат кэшируется постранично.

Из абзацев собираются фрагменты: заголовок приклеивается к своему тексту, длинные абзацы режутся по предложениям,
отбрасываются дисклеймеры и колонтитулы, таблицы, подписи и оси графиков. Почему что отброшено — в `report.json`.

Качество на материалах кейса: текстовые страницы распознаются почти дословно (уверенность 93–96), ошибки единичные
(«ЕТЕ» вместо ETF, запятая вместо точки). Слабее слайды «Тактический взгляд на 3-й квартал», где текст стоит вплотную
к графику: часть фрагментов содержит подписи осей. Уверенность есть у каждого фрагмента (`ocr_confidence`), по ней
можно отсечь шумные; такие страницы — первые кандидаты на Qwen3-VL.

Название и дата материала — из [`src/ingest/analytics/catalog.toml`](src/ingest/analytics/catalog.toml); для нового
файла без карточки дата берётся с первой страницы или из имени файла.
