# Сбор материалов: новости и аналитика банка

Пакет готовит материалы, на которые опирается сервис: свежие новости из открытых лент и аналитику Центра
макроэкономического анализа Альфа-Банка. Всё приводится к схеме `Source` — общему формату обмена с API.

```
RSS-ленты ──▶ нормализация ──▶ склейка дублей ──▶ факторы и отрасли с силой ──▶ raw/derived/news.jsonl
                                                   ожидания рынка (фича F)      demo/news_snapshot.jsonl (в git)

PDF-сканы ──▶ страница в картинку ──▶ Tesseract ─────────┬─▶ страницы целиком ──▶ raw/derived/alfa_pages.jsonl
              (pypdfium2)             Qwen3-VL (таблицы,  └─▶ фрагменты ────────▶ raw/derived/alfa_fragments.jsonl
                                      один раз, из кэша)
```

## Запуск

Одна команда из корня репозитория — соберёт новости и соберёт аналитику:

```bash
docker compose -f apps/ingest/compose.yaml run --rm ingest
```

PDF аналитики кладутся в `data/raw/alfa_analytics/` (материалы кейса, в git их нет). Первый прогон распознаёт
64 страницы Tesseract за 3–6 минут, дальше страницы берутся из кэша `data/raw/derived/ocr/`. Модели по умолчанию не
вызываются: распознанное Qwen3-VL берётся из кэша, если он есть.

Без Docker (нужны Python 3.12 и [uv](https://docs.astral.sh/uv/)):

```bash
cd apps/ingest
uv sync
uv run ingest all --data ../../data              # новости и аналитика
uv run ingest news --data ../../data --snapshot  # только новости, обновить снимок в data/demo
uv run ingest analytics --data ../../data --vlm  # распознать недостающие страницы Qwen3-VL (платно)
uv run pytest
```

Локально нужен Tesseract с русским языком: `apt install tesseract-ocr tesseract-ocr-rus`, `brew install tesseract
tesseract-lang`, на Windows — сборка UB Mannheim. Если его нет, всё собирается из кэша распознавания; страницы, которых
нет в кэше, перечислены в выводе и в `report.json` (`missing_pages`, `errors`), остальные страницы материала идут в
работу.

**Сбои не роняют прогон.** Нет ключа или сети, кончился бюджет, ошибка модели или Tesseract — страница остаётся
нераспознанной, новые платные запросы после первой ошибки не отправляются, ошибка в кэш не пишется. Новость, которую
модель не разметила, остаётся с разметкой словарей. Кэш привязан к содержимому PDF: новый выпуск под старым именем
распознаётся заново.

| Параметр | Что делает |
|---|---|
| `--data` | каталог данных, по умолчанию `./data` |
| `--engine` | основное распознавание: `tesseract` (по умолчанию) или `qwen3-vl-mock` |
| `--vlm` | распознать страницы, которых нет в кэше, моделью Qwen3-VL-30B-A3B-Instruct |
| `--llm` | разметка новостей моделью поверх словарей: `off` (по умолчанию), `mock`, `api` (Gemma 4 26B A4B) |
| `--feeds` | свой файл лент вместо встроенного `sources.toml` |
| `--snapshot` | перезаписать `data/demo/news_snapshot.jsonl` |
| `--force` | распознать страницы заново |

Для `--vlm` и `--llm api` нужны переменные `LLM_API_KEY` и `LLM_BASE_URL` (OpenAI-совместимый API организаторов);
compose берёт их из `.env` в корне. Каждый вызов модели пишется в `data/raw/derived/llm_calls.jsonl`: цель, модель,
токены, стоимость, время. Ключ в журнал и вывод не попадает.

## Загрузка в БД и обновление по расписанию

Материалы ложатся в ту же PostgreSQL, что у API (`DATABASE_URL`), в свои таблицы: `news`, `alfa_materials`,
`alfa_pages`, `alfa_fragments` (схема — [`src/ingest/db/schema.py`](src/ingest/db/schema.py), версия своя, таблицы
компаний не трогает). Поиск по ним — `apps/api/src/api/search`.

```bash
uv run ingest load --data ../../data              # снимок, raw/derived/news.jsonl и аналитика — в БД
uv run ingest serve --data ../../data --every 30  # то же, затем новости из лент в БД каждые 30 минут (compose)
```

- **Без дублей.** Новость с тем же id обновляется, только если поменялась; неизменившиеся файлы аналитики не
  перечитываются, изменившиеся заменяют набор целиком в одной транзакции. Новость, сюжет которой уже есть в базе (те
  же правила склейки, окно 48 часов), не заводит второе событие — она дописывается в `also_reported_by`; id события
  не меняется, на него ссылаются инсайты.
- **Новости не удаляются.** Ленты отдают только последние записи — история копится в базе.
- **Снимок только добавляет**: запись, которая уже есть в базе, им не перезаписывается — в базе версия свежее.
- **Без сети** ленты не отвечают, в базе остаётся загруженное (снимок и прошлые сборы). Сбой БД — повтор на следующем
  круге. `serve` файлы не пишет (в compose каталог данных подключён только на чтение) и PDF не распознаёт — это
  `ingest analytics` или `ingest all`.
- Смена версии схемы (`SCHEMA_VERSION`) пересоздаёт таблицы при следующей загрузке: накопленные из лент новости и
  присланные на разбор теряются, снимок и аналитика загружаются заново. API при старте таблицы только создаёт.
- В базе хранится текст страниц аналитики — для сверки цитат банка внутри сервиса; наружу API отдаёт только фрагмент
  до 600 знаков с файлом и страницей.
- **Картинки и полный текст со страниц.** После загрузки (и в `serve` — после каждого сбора) до 200 свежих новостей
  за круг, которые ещё не проверяли, дозаполняются со страницы материала: ссылка на og:image, если картинки нет в
  ленте, и полный текст — только у лент с `full_text = "page"`. Страница не ответила — новость остаётся на следующий
  круг (не больше трёх кругов, если сеть есть, а сайт не отвечает; 429 и 5xx — тоже повтор); ответила — помечается
  `media_checked_at` и больше не запрашивается. Одна и та же картинка у трёх и более новостей издателя — заглушка
  сайта: она запоминается в `news_image_stubs` и больше не берётся ни из ленты, ни со страницы. Значок издания старым
  новостям проставляется по издателю; полный текст издателей, которым его больше не разрешает `sources.toml`,
  удаляется при загрузке. Текст, присланный пользователем на разбор, наружу как полный текст не отдаётся.

## Что получается

| Файл | Содержимое |
|---|---|
| `data/raw/derived/news.jsonl` | новости по схеме `Source`, свежие с последнего запуска |
| `data/raw/derived/alfa_pages.jsonl` | страницы аналитики целиком: `src:alfa:<материал>#p<N>` — для дословной сверки цитат банка |
| `data/raw/derived/alfa_fragments.jsonl` | фрагменты аналитики для поиска: `src:alfa:<материал>#p<N>-<номер>` |
| `data/raw/derived/ocr/<движок>/<материал>/pNNN.{json,txt}` | кэш распознавания: абзацы с рамками и текст для проверки глазами |
| `data/raw/derived/report.json` | отчёт: какие ленты ответили, что и почему отброшено или заменено на каждой странице |
| `data/raw/derived/llm_calls.jsonl` | журнал вызовов моделей |
| `data/demo/news_snapshot.jsonl` | снимок новостей для работы без сети: заголовок, лид до 500 знаков, ссылка, издатель, дата, разметка |

Если ни одна лента не ответила, `news.jsonl` заполняется из снимка — сервис не остаётся без новостей.

У новости есть `image_url` (картинка: media:content, media:thumbnail, вложение или `<img>` из ленты, иначе og:image
страницы — храним только ссылку), `source_icon_url` (значок издания) и `text` (полный текст — где его разрешают
условия, см. ниже; в БД — колонка `body`).

Пример новости (сокращено):

```json
{"id": "src:news:3f1c…", "kind": "news", "title": "Цена нефти Brent превысила $112 за баррель впервые с мая",
 "publisher": "Коммерсантъ", "url": "https://www.kommersant.ru/doc/…", "published_at": "2026-10-22T18:05:00+03:00",
 "fragment": "лид дословно, до 500 знаков",
 "tags": {
   "factors": [{"code": "commodity_oil_gas", "name": "сырьё: нефть и газ", "strength": 1.0,
                "evidence": ["«нефти» в заголовке", "«brent» в заголовке"]}],
   "sector_links": [{"okved": "06", "name": "добыча нефти и газа", "strength": 1.0, "via": "text",
                     "evidence": ["«нефти» в заголовке"]},
                    {"okved": "19", "name": "нефтепереработка и топливо", "strength": 1.0,
                     "via": "factor:commodity_oil_gas", "evidence": ["…"]}],
   "okved": ["06", "09", "19"], "event_type": "рынки", "regions": [], "countries": [],
   "topics": ["сырьё: нефть и газ"], "sectors": ["добыча нефти и газа"], "tagged_by": ["rules"]},
 "expectations": [],
 "also_reported_by": [{"publisher": "Интерфакс", "title": "…", "url": "…", "published_at": "…"}]}
```

`topics`, `sectors`, `okved` — плоские списки для совместимости с контрактом; полная информация — в `factors` и
`sector_links`. Все поля сверх контракта необязательные.

## Источники новостей

Список — в [`src/ingest/news/sources.toml`](src/ingest/news/sources.toml): добавить источник — дописать блок, код не
меняется. Включены ленты, условия которых допускают заголовок, лид и ссылку:
- официальные — Банк России, Правительство, ФНС;
- агентства — Интерфакс, РИА Новости;
- деловые СМИ — Коммерсантъ, Forbes;
- прочие СМИ — «Российская газета», «Известия».

Выключенные описаны с причиной в `terms`: условия запрещают автоматическое извлечение или не найдены, либо сайт не
отвечает. Подробно — в [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

**Полный текст** храним только там, где условия издателя это разрешают (`full_text` у ленты): Банк России,
Правительство и ФНС — со страницы материала (`text_container` — класс элемента со статьёй, если общий разбор берёт
не то), Forbes — из ленты, издатель сам кладёт туда полный текст. У остальных условия разрешают только цитирование,
поэтому у них лишь лид; пейволлы не обходим, страниц платных материалов не запрашиваем.

**Каталог источников для бизнеса** — [`src/ingest/news/catalog.toml`](src/ingest/news/catalog.toml), загрузка —
`ingest.news.catalog.load_catalog()`, отдаёт API (`GET /api/sources/catalog`). Для руководителя: `about` (что это
за источник), `benefit` (что даст подключение, одной фразой), `access` (бесплатно или по подписке), `note`
(ограничение человеческим языком: «сейчас недоступно для компаний из России»), `industries` (префиксы ОКВЭД — по ним
API ставит пометку «для вашей отрасли»). Для подключающих — `how_to_connect` (шаги, техника — только здесь), `docs_url`,
у платных `key_env` (переменная в `.env` на сервере). Ещё `country` (`ru` / `intl`), `kind` (`free` / `paid_api`),
`reliability`, `topics`; `connected` — включена ли хотя бы одна его лента из `feeds`. Коннекторов к платным API в
прототипе нет.

**Отраслевые ленты** (26.10): ФАС и Россельхознадзор (официальные, для торговли, поставщиков продуктов и экспорта зерна)
и Retail.ru, New Retail (розница, продукты, общепит). ФАС и Россельхознадзор из сети разработки не отвечают — только с
сервера стенда. У Минсельхоза, ЕЭК и Минэкономразвития открытой ленты нет.

**Надёжность источника** (`reliability` у ленты): `official`, `agency`, `business_media`, `other`. Она попадает в
новость и в базу и служит «качеством источника» в ранжировании для издателей, которым не задан свой множитель
(`[source_tiers]` в `apps/api/src/api/roles.toml`). **Домены ленты** (`hosts`): запись со ссылкой на другой сайт —
спорт-сайт агентства, журнал партнёра — не берётся, чтобы в карточке был верный издатель.

**Склейка дублей.** Сначала одна и та же ссылка из разных лент, затем один сюжет у разных издателей: совпадение основ
слов в заголовках (Жаккар ≥ 0,5 или короткий заголовок почти целиком внутри длинного) в окне 48 часов. Разные
названия мест и компаний («аэропорт Сочи» и «аэропорт Казани») и разные числа («до 16%» и «до 14%») — разные
события. Главной остаётся запись первоисточника (регулятор раньше СМИ), остальные — в `also_reported_by`.

## Разметка: факторы и отрасли с силой связи

Словари и правила — в [`src/ingest/tagging/dictionaries.toml`](src/ingest/tagging/dictionaries.toml), расширяются без
правки кода.

**Факторы** — каталог карты чувствительности: `rate` (стоимость заёмных денег), `deposit_yield` (доходность свободных
денег), `fx`, `ved_logistics` (санкции, платежи и логистика ВЭД), `consumer`, `labor`, `gov`, `commodity_metals`,
`commodity_oil_gas`, `commodity_gold`, `commodity_fertilizers`, `commodity_agro`, `inflation` (инфляция издержек),
`region`. Сверх каталога — `tax_regulation` (налоги и регулирование): его вес нужен роли главбуха. Факторы `demand_*` и
`supply_*` считаются на стороне компании по платежам; новость даёт для них отрасли с силой связи.

**Отрасли** — 42 группы двузначных кодов ОКВЭД 2, разбитые так, чтобы новость задевала только свои коды: аэропорт —
это 52 (транспортная инфраструктура) и 51 (авиаперевозки), но не 53 (почта). Сырьевой фактор добавляет отрасли,
которых касается напрямую, с весом (`implies`): нефть → 06, 19 и 09 слабее; такая связь помечена
`via: "factor:<код>"`, а названная в тексте отрасль — `via: "text"`.

**Сила связи** 0–1, пороги как у карты чувствительности (высокая ≥ 0,6, средняя ≥ 0,3): сильный шаблон в заголовке —
1,0; слабый в заголовке или сильный в лиде — 0,6; слабый только в лиде — 0,3; каждое следующее совпадение +0,1.
У каждой связи — `evidence`: найденные слова и где они стоят. Так ранжирование раскладывает вклад события на слагаемые.

**Тип события, регионы России, страны** — там же.

Шаблоны ищутся с начала слова, поэтому основа покрывает все формы: `инфляц` найдёт «инфляция» и «инфляционных».
Ложные срабатывания закрыты исключениями и тестами: «газета», «Газпромбанк», «Группа ГАЗ» — не газ, «органы опеки» —
не ОПЕК, «банкротство» — не банк, «Евразийский» — не ЕВРАЗ, «Международный валютный фонд» — не валюта, «страховые
взносы» — налог, а не страхование, «вышел в прокат» — не металлопрокат, «карьера» — не карьер, «рекламный бюджет» —
не госрасходы, «потребление электроэнергии» — не потребительский спрос, «пластиковые карты», «сахарный диабет»,
«розничные инвесторы», «Московская биржа» и «СПБ Биржа» — мимо отраслей и регионов.

**Слово не привязывает отрасль само по себе.**
- «Утильсбор» относится к той технике, что названа рядом: «утильсбор на легковые автомобили» — торговля автомобилями,
  «утильсбор на буровое оборудование» — машиностроение.
- «Подтяжка лица без пластики» — не пластмассы, «банк фото и изображений» — не банки.
- «Цифровой рубль» и «цифровые финансовые активы» — не ИТ.

**Новость только о других странах** (раздел `[foreign]` словаря). Признак: в новости нет России, российских регионов
и российских признаков, а в заголовке названы две чужие страны или одна без торговых слов.
- Российские признаки — рубль, российские ведомства, крупные компании и бренды, «наши».
- Ведомство чужой страны («Минфина США», «ЦБ Турции») российским признаком не считается.
- Чужая страна только в тексте — это сравнение («…банки США поступили так же»), новость наша.
- Выход нашей компании за рубеж («Аэрофлот возобновил рейсы в Египет», «Ozon открыл склад в Казахстане») считается
  торговлей, такую новость не трогаем.
- С такой новости снимаются «ВЭД» и «налоги и регулирование»: пошлины США для Канады — не наша торговля, а лицензия
  Минфина США — не наше регулирование.
- Отрасли, названные в её тексте, — не сильнее 0,3, с пометкой «событие в других странах — связь косвенная».
  Пример: «в Киеве отключили электроэнергию».
- Отрасли через сырьевые факторы не ослабляются: цены на нефть и газ мировые.
- Одна чужая страна плюс торговля — это наша торговля с ней, хотя Россия не названа: «импорт автомобилей из Китая
  упал». Такую новость не трогаем.

**Регион** становится фактором «события региона», только если в новости есть экономика региона (раздел
`[region_economy]`): налоги и сборы, бюджет и госзаказ, аренда и земля, ограничения для транспорта, меры поддержки
бизнеса. «В Москве мотоциклист сбил пешехода» — место (`tags.regions`), но не фактор.

**Деловая или нет** (`tags.business`, причина — `tags.business_reason`). Лента отсеивает спорт, происшествия, культуру,
погоду, светскую хронику, поздравления и политические заявления без экономики до ранжирования:
- словари: сильный деловой признак в заголовке (фактор или отрасль) — деловая; не деловая категория (`[[offtopic]]`)
  без делового следа — нет; строгие категории (поздравления, спорт) сильнее признака — «Мишустин поздравил
  таможенников» не новость о таможне;
- сомнительные (`business = null`: только слабые признаки, или не деловая категория рядом со словами о бизнесе из
  `[business_words]`) решает модель — `ingest classify` и каждый круг `ingest serve`, если в окружении есть ключ.
  Самая дешёвая из разрешённых — Gemma 4 26B A4B, 20 новостей в запросе, только новости за 14 дней; ответ ложится в
  таблицу `news_business` (это и кэш — второй раз не спрашиваем, переразметка его не стирает). Суточный бюджет —
  `INGEST_LLM_DAILY_BUDGET_RUB` (10 ₽), расход считается по журналу `LLM_JOURNAL`. Без ключа сомнительные остаются в
  ленте. Замер на 708 новостях: словари отсеяли 122, оставили 257 деловыми, 329 отдали модели; модель за 14 запросов
  (0,24 ₽) отсеяла 193 из 276 за последние 14 дней.
- `api.search`: `list_news` и `search_news` не возвращают не деловые, `include_non_business=True` (и тот же параметр
  `GET /api/news`) — вернуть.

**Переразметка.** Если словари или правила поменялись, `ingest load` и `ingest serve` при старте заново размечают
новости, уже лежащие в базе. Изменение определяется по отпечатку файлов, размеченные моделью новости не трогаются.
Без этого исправление не дошло бы до новостей, которых уже нет в лентах.

**Разметка моделью** — `--llm api`, Gemma 4 26B A4B, поверх словарей: модель добавляет факторы и отрасли, которые
правила пропустили, и уточняет силу. Ответ проверяется: неизвестные коды отбрасываются, доказательство должно стоять
в тексте новости целыми словами и быть не короче 4 знаков, кривой JSON даёт пустую разметку, текст новости передаётся
как данные, а не инструкции. Ответы кэшируются по id.
Проба на 8 новостях: 0,097 ₽ (около 0,012 ₽ и 4 секунд на новость). Модель добавляет тип события и уточняет силу, но
местами предлагает натянутые связи, поэтому по умолчанию выключена.

## Ожидания рынка (фича F)

Для сравнения «банк против рынка» из заголовка и лида извлекаются предложения с ожиданиями: кто ожидает (`analysts`,
`market`, `international`, `regulator`, `government`, `company`, `bank`, `other`), по какому фактору (`indicator` — код
из каталога), какие числа (`values`, включая «$120») и сама фраза дословно (`quote`). Если показателя в предложении
нет, но известно, кто ожидает, он берётся из предыдущего предложения («Brent превысила $112. Аналитики ожидают роста до
$120.»), кроме прогнозов по показателям вне каталога (ВВП). Без показателя из каталога ожидание не сохраняется —
сравнивать с банком нечего. «Инфляционные ожидания» — показатель, а не чей-то прогноз, их не берём. Полного текста
статей нет, поэтому ожидания — только из лида, и их немного: в снимке 5 на 362 новости.

## Рыночные ряды: курсы, ставка, нефть

Таблица `market_series` (series, day, value, unit, source, fetched_at) — ряды для рыночных выводов API:
`usd_rub`, `eur_rub`, `cny_rub`, `aed_rub`, `inr_rub` (официальные курсы ЦБ на дату, ₽ за 1 единицу с учётом номинала),
`key_rate` (ключевая ставка ЦБ, % годовых, по дням действия), `brent_usd` (нефть Brent, $ за баррель, EIA).
Подписи и ссылки на источники — в справочнике `ingest.market.SERIES`.

- Обновляются каждый круг `ingest serve`, а вручную — `ingest market`. Загружаются только недостающие дни, с перекрытием
  в неделю (ЦБ и EIA уточняют данные задним числом).
- История: валюты и нефть — 90 дней, ставка — 180 дней (изменение «за три месяца» должно найти точку на «сейчас − 90»).
- Источник, который не ответил, не мешает остальным — ошибка выводится в отчёте круга.
- Зерно не грузим: открытого ежедневного ряда с понятными условиями использования не нашли.

## Аналитика банка: распознавание

PDF аналитики — сканы без текстового слоя. Страница рендерится в картинку (длинная сторона 3500 px, около 300 dpi).

**Два движка, потому что они сильны в разном.** Сравнение на трёх страницах (текст, слайд с графиком, таблица
прогнозов):

| | Tesseract 5 (`rus+eng`) | Qwen3-VL-30B-A3B-Instruct |
|---|---|---|
| Текстовая страница «Ключевая ставка» | почти дословно, уверенность 93–96 | пересказывает: опускает слова, меняет обороты |
| Слайд «Конъюнктура рынка» | текст перемешан с подписями графика | чисто, но изредка пропускает слова |
| Таблица прогнозов 1П26, стр. 4 | каша | вся таблица по строкам, цифры сверены с картинкой |
| Стоимость | бесплатно | около 0,15 ₽ и 40–60 секунд на страницу |

Поэтому:

- **страница целиком** (`alfa_pages.jsonl`) — текст Tesseract в `fragment` и текст Qwen3-VL в `vlm_text`. Цитату банка
  сверяют с текстом того движка, что указан у фрагмента в `ocr_engine`: `ingest.analytics.quotes.quote_in_page`
  (совпадение с точностью до пробелов и переносов, пересказ не проходит);
- **фрагменты** (`alfa_fragments.jsonl`) — основа Tesseract. Фрагмент Qwen3-VL добавляется, если меньше половины его
  слов есть в надёжных (уверенность ≥ 85) фрагментах Tesseract — это таблицы и текст рядом с графиками. Испорченный
  фрагмент Tesseract (уверенность ниже 70, текст перемешан с графиком) заменяется фрагментом Qwen3-VL, который его
  покрывает; от 70 до 85 остаётся Tesseract — он дословнее. Таблицы Qwen3-VL идут вместе с подписью («Табл.2: …»),
  строки — через « | »; таблицы без подписанных строк — это оцифрованные оси графиков, они отбрасываются.

**Сверка Tesseract с Qwen3-VL** ([`src/ingest/analytics/ocr_fixes.py`](src/ingest/analytics/ocr_fixes.py)).
Tesseract на русских сканах путает похожие буквы: «конец» читает как «KOHeL», «Рис.» — как «Puc.», «этом» — как
«stom», «руб.» — как «py6.», «2026 г.» — как «2026 r.», «г/г» — как «rir», «й» — как «и» («воздеиствовать»), а в кодах
ISIN — «O» вместо нуля. Такое слово заменяется, только если:
- его нет в тексте Qwen3-VL той же страницы;
- исправленный вариант там есть и он единственный (из «этот» и «этом» выбирает соседнее слово, как у Qwen);
- это не число, не аббревиатура до трёх букв (рейтинги BBB, MTC) и не код, которого нет у Qwen.

Исправляются блоки до сборки, поэтому страница и её фрагменты остаются дословно согласованы. Каждая замена записана
у страницы в `ocr_fixes` («KOHeL → конец»). Сейчас таких замен 74 на 22 страницах (30 из них — коды ISIN), выборочно сверены с картинками страниц.

**Мусор вместо текста** (легенды графиков вроде «ммм очучуоуохооо… SOA AN NN»). Такой фрагмент Tesseract заменяется
фрагментом Qwen, а если подходящего нет — отбрасывается и не попадает в цитаты. Признак мусора: больше 30 % его слов
нет в тексте Qwen той же страницы (считаются слова от трёх знаков) при уверенности ниже 80.

Фрагментов стало 276 вместо 282:
- 4 отброшены как мусор;
- легенда графика (золото, стр. 7) заменена фрагментом Qwen;
- список ISIN (стратегия, стр. 24) после правки O→0 стал таблицей из цифр, верные коды есть в таблице Qwen.

Для фич, где важна дословность (цитата банка), лучше брать фрагменты Tesseract; для чисел из таблиц — фрагменты
Qwen3-VL. Проверено на всех 276 фрагментах: каждый целиком находится в тексте своей страницы, а слов, где латиница
смешана с кириллицей, нет — кроме кодов облигаций (`БО-001Р-05`). Тест — `tests/test_ocr_fixes.py`.

Qwen3-VL вызывается один раз (`--vlm`), результат кэшируется постранично и дальше берётся из кэша. Распознавание
всех 64 страниц стоило 7,39 ₽ и заняло 13 минут. Если модель зацикливается и повторяет фразу до лимита токенов (так
было на двух страницах-дисклеймерах), повтор обрезается.

Из абзацев собираются фрагменты: заголовок приклеивается к своему тексту, длинные абзацы режутся по предложениям,
отбрасываются дисклеймеры и колонтитулы, подписи и оси графиков. Склеиваются только соседние блоки страницы, поэтому
каждое предложение фрагмента стоит в тексте страницы подряд. Почему что отброшено или заменено — в `report.json`.

Название и дата материала — из [`src/ingest/analytics/catalog.toml`](src/ingest/analytics/catalog.toml); id материалов
совпадают с разбором позиции банка. Отчёт «Российская сталь» 2021 года помечен `stale: true`: это не позиция банка
на сегодня, из поиска по умолчанию его стоит исключать.
